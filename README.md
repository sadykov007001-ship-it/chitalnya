# Читальня

Личная читалка электронных книг в браузере. Работает на iPhone, Android и компьютере, ставится на главный экран как приложение и читает без интернета.

**Форматы:** EPUB, FB2, FB2.ZIP, FBZ, MOBI, AZW, AZW3, PDF, DJVU, TXT (UTF-8, windows-1251, KOI8-R), RTF, DOCX, ODT, HTML, Markdown, комиксы CBZ, CBR, CB7. Старые DOC и CHM нужно перевести в EPUB (например, бесплатным Calibre).

**Возможности:** выделение пятью цветами, подчёркивание, заметки, закладки, оглавление, поиск по книге, темы и шрифты, листание страницами или прокруткой, цитаты из всех книг. Синхронизация книг, места чтения и заметок между устройствами через ваш Dropbox.

Книги и заметки хранятся только на ваших устройствах и в вашем Dropbox.
